#Task 1 : Command-Line BMI Calculator

## Projrct Description
This is a biginner-level Python program developed for the Oasis Infobyte Internship.It prompts users to enter their weight in kilograms and height in meters,calculates their Body Mass Index (BMI), and classifies it into health categories like Underweight, Normal, Overweight, or Obese based on predefined ranges.

## Features
1. User Input Validation(handles negative values and letters gracefully)
2. Accurate BMI Calculation using the standard formula
3. Clear health category status output
